# Part F — Mathematical Expressions

## Mean

The arithmetic mean can be represented as:

**Mean = Σx / n**

where `Σx` represents the sum of all observations and `n` represents the number of observations.

## Classification Accuracy

Accuracy can be calculated using:

**Accuracy = (TP + TN) / (TP + TN + FP + FN)**

where:

* **TP** = True Positive
* **TN** = True Negative
* **FP** = False Positive
* **FN** = False Negative
